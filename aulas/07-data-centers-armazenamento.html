Objetivos da aula

  • Entender a organização física e lógica de um data center
  • Conhecer os principais dispositivos de comunicação e armazenamento
  • Compreender o conceito de consolidação de serviços

O que é um data center?

Instalação física dedicada a abrigar servidores, equipamentos de rede e armazenamento, com infraestrutura de energia, refrigeração e segurança para mantê-los funcionando 24/7.

É o “prédio” físico por trás de toda a nuvem que estudamos até aqui.

Organização física de um data center

  • Racks — estruturas padronizadas (medidas em unidades “U”) onde servidores são empilhados verticalmente
  • Refrigeração (cooling) — um dos maiores gastos energéticos; corredores quentes/frios organizados para otimizar o fluxo de ar
  • Energia redundante — geradores e nobreaks (UPS) para garantir funcionamento mesmo em queda de energia
  • Cabeamento estruturado — organização de cabos de rede e energia para facilitar manutenção
  • Segurança física — controle de acesso, câmeras, biometria

Tiers de data center (classificação de confiabilidade)

Tier Disponibilidade Redundância
I ~99,67% Nenhuma
II ~99,75% Componentes redundantes
III ~99,98% Manutenção sem parar o serviço
IV ~99,99% Tolerante a falhas, tudo duplicado

Não é preciso decorar os números — o importante é entender que existe uma escala formal de confiabilidade, usada por provedores de nuvem para classificar seus data centers.

Dispositivos de comunicação

  • Switches — conectam os equipamentos dentro do data center (rede local de alta velocidade)
  • Roteadores — conectam o data center a outras redes e à internet
  • Firewalls — controlam e filtram o tráfego de entrada/saída por segurança
  • Load balancers — distribuem requisições entre vários servidores, evitando sobrecarga em um único ponto

Dispositivos de armazenamento

  • DAS (Direct-Attached Storage) — armazenamento conectado diretamente a um único servidor
  • NAS (Network-Attached Storage) — armazenamento compartilhado via rede, acessível por vários servidores/usuários (arquivos)
  • SAN (Storage Area Network) — rede dedicada de alta velocidade, exclusiva para tráfego de armazenamento em bloco, usada em ambientes de alta performance

DAS x NAS x SAN

DAS NAS SAN
Conexão Direta a 1 servidor Via rede comum Rede dedicada
Compartilhamento Não Sim (arquivos) Sim (blocos)
Performance Alta (local) Média Muito alta
Uso típico Servidor único Compartilhamento de arquivos Data centers/bancos de dados críticos

RAID — redundância de disco

RAID (Redundant Array of Independent Disks) combina vários discos físicos para ganhar performance e/ou tolerância a falhas:

  • RAID 0 — divide dados entre discos (mais velocidade, zero redundância)
  • RAID 1 — espelha os dados em dois discos (redundância total, menos espaço útil)
  • RAID 5 — distribui dados + paridade entre 3+ discos (bom equilíbrio custo/segurança)

Nota

Data centers de nuvem usam RAID (ou tecnologias equivalentes) para garantir que a falha de um disco físico não derrube nenhum dado de clientes.

Consolidação de serviços

Reunir várias cargas de trabalho (que antes rodavam em servidores físicos separados e subutilizados) em menos servidores físicos, usando virtualização.

Por que consolidar?

  • A maioria dos servidores físicos tradicionais roda subutilizada (muitas vezes menos de 15% de uso médio de CPU)
  • Consolidar via virtualização = mais VMs por servidor físico, aproveitando melhor o hardware
  • Resultado direto: menos hardware, menos energia, menos espaço, menos custo — reforça a conexão com TI verde vista na Aula 03

Como se calcula (de forma simplificada)

  1. Medir o uso médio de CPU/RAM de cada servidor físico atual
  2. Somar as necessidades reais de todos eles
  3. Dimensionar um servidor físico novo, mais potente, capaz de rodar todos como VMs, com folga de segurança
  4. Migrar os serviços para VMs nesse novo servidor consolidado

Exemplo numérico simples: 8 servidores físicos usando em média 10% de CPU cada → provavelmente cabem todos como VMs em 1-2 servidores físicos modernos.

Atividade da aula

Em grupos (10 min):

Uma empresa tem 6 servidores físicos separados (e-mail, site, banco de dados, arquivos, backup, DNS), cada um usando em média 12% de CPU.

  1. Proponham um plano de consolidação: quantos servidores físicos vocês manteriam?
  2. Que tipo de armazenamento (DAS/NAS/SAN) vocês recomendariam para os arquivos compartilhados da empresa?
  3. Que nível de RAID vocês usariam para o servidor de banco de dados crítico? Justifiquem.

Síntese da aula

  • Data centers têm organização física (racks, refrigeração, energia) e são classificados por Tiers
  • Dispositivos de comunicação (switches, roteadores, firewalls, load balancers) e armazenamento (DAS, NAS, SAN) formam a infraestrutura
  • RAID garante redundância de dados em disco
  • Consolidação de serviços usa virtualização para reduzir hardware físico, custo e energia
